# Holopolis: Chelsea

A Unity / Meta Quest project for an evidence-based Chelsea miniature and street
exploration. The current deliverable is the **M0 + first-area M1 foundation** from
the attached specification, not a completed VR experience.

See [chelsea/README.md](chelsea/README.md) for setup and validation,
[the milestone plan](chelsea/PLAN.md), and
[the verification report](chelsea/docs/VERIFICATION.md) for exact completion status.

For the Mac + Quest native diagnostic launch path, see
[LAUNCH_MAC.md](chelsea/docs/LAUNCH_MAC.md). It includes build/install source and
remaining blockers; no Unity build or headset result is claimed.
