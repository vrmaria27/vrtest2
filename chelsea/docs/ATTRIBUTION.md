# Attribution and permitted use

Research date: 5 November 2026. This is an M0/M1 foundation, not a cleared visual-asset release.

## OpenStreetMap geographic data

Required credit whenever OSM-derived geography is displayed:

> © OpenStreetMap contributors. Data available under the Open Database License (ODbL) 1.0. https://www.openstreetmap.org/copyright

License: https://opendatacommons.org/licenses/odbl/1-0/

The OSM website's own English copyright text was inspected through its official GitHub repository at commit `2dedaf4946ffc522679483126ef7b18c68de1c66`:

https://github.com/openstreetmap/openstreetmap-website/blob/2dedaf4946ffc522679483126ef7b18c68de1c66/config/locales/en.yml

That source explicitly permits copying, distributing, transmitting and adapting OSM data with contributor credit, and describes same-licence requirements for adaptations. Direct access to the public copyright page and OSMF attribution page was denied by the session network proxy (CONNECT 403); this is not a completed review of the detailed legal code or current attribution guidelines.

Keep the frozen source extract, source IDs, retrieval date, checksums and transformation instructions beside any derived database. Distributing an adapted database can require ODbL share-alike and an offer of the corresponding database in a machine-readable form. Rendered meshes can have different Produced Work obligations; do not assume exporting a mesh removes the underlying database obligations. Review the actual distribution package and full ODbL terms before release. Keep project source code licensing separate from data licensing.

Show the credit in the review viewer and the eventual in-app attribution view, with a readable offline copy or URL. Do not depend on an online click for an installed offline experience. No third-party map tiles are required or licensed by an OSM data import.

## Models, imagery and audio

No Google imagery, panoramas, meshes, user-review text or screenshots are imported. Google Maps/Street View has **not** been reviewed; terms and geographic-content guideline requests were blocked by network policy, so permitted visual comparison has not been established. Google is not a geometry or asset source.

No rights-cleared façade photographs, bespoke landmark models, textures or recordings have been obtained at this milestone. Generic diagnostic extrusion is not a finished landmark or a visual reference. Public access to council documents, official landmark websites or photographs does not grant redistribution or reconstruction rights.

Future assets require: author/provider, original URL, asset version/checksum, licence and attribution text, allowed modifications, and import/generation settings. Do not ship an asset with unknown permission. User-owned photographs must be accompanied by an explicit permission record; do not infer ownership from an upload alone.
